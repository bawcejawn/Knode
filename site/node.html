The network in this window

The same things Knode Games' network questions ask about.

Each block goes to a running producer at random, in proportion to its VHP, so counts swing: the likely range covers 8 times out of 10. Shares use the VHP each producer holds now. KOIN per block is the network's recent average reward after the VHP a block uses. Blocks already read are kept in this browser, so later visits only read new ones.
